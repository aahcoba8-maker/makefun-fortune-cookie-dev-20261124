# Fortune Cookie Wisdom for Developers

One original fortune-cookie line for a software developer, written by a program
that outputs it to `entry.txt`.

> Your future self will debug your code at 3 a.m.; leave them a comment, a test, and an apology.

## Entry

- `main.py` — stdlib-only; writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
  (fallback `/output`, then the script directory). No trailing newline, so the
  file holds exactly the 94-character line.
